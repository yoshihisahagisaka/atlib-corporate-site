# atLIB Secure Guard — PIRA傘下企業 市場構造・PC台数・料金適合性調査

調査日: 2026-10-17  
対象: PIRA（一般社団法人 国際連携推進協会）正会員の傘下企業。賛助会員は販売対象に含めない。  
用途: 料金設計、PIRA提案、事業性の感度分析。正式な料金決定・契約判断には用いない。

## 結論（経営判断用）

**条件付きで妥当。** 現行の「基本料金 5,000円/社/月 + 端末料金 300円/台/月」は、少人数企業にも固定費で運用・窓口・標準セキュリティを提供する前提なら説明可能である。一方、1〜5台企業では月額の大部分が基本料金となるため、価格を先に下げるよりも、何を含むか（導入支援、標準ポリシー、検知・問い合わせ窓口）を明確にし、無料診断から価値を可視化することが必要である。

提案中の**限界単価型**段階割引（1〜10台: 300円、11〜30台: 250円、31〜100台: 200円、101台以上: 個別見積）は、今回の基準シナリオ（平均 9.85 台/社）では端末売上をほぼ削らず、大口だけに価格調整余地を与えるため合理的な出発点である。ただし、PIRA傘下企業の実際のPC台数分布は未取得であり、正式採用は無料診断または申込前ヒアリングで少なくとも100社分の台数・業種を取得してから再評価する。

会員名簿は「ホームページ掲載を許可した会員のみ」を地域別に掲示する。したがって、公開掲載数を74の母数として使わない。今回の集計CSVでは、公式総数（74、約10,000社）と公開名簿由来の情報を分離した。

公開名簿には東京・東日本・西日本の地域区分と、協同組合、事業協同組合、株式会社、一般社団法人、学校法人等の名称が掲示されている。名称からは、協同組合・監理支援を担う団体が中心で、情報システム、農業、金属プレス、介護、人材、物流等の手掛かりが一部に見える。

ただし、これは**PIRA会員団体の名称・取扱領域**であり、傘下約10,000社の業種構成ではない。傘下企業の業種別社数は未確認で、以下を確定値として扱わない。

## 4. Windows PC台数のシナリオ（推計）

直接的なPIRA傘下企業のPC台数統計は確認できなかったため、事務・営業・現場管理・設計技術・共用PCを含む「Windows保護対象」を台数帯で仮定した。0台/対象外は、PCをほぼ利用しない企業、Mac等のみ、導入対象外を含む。

| Windows PC台数帯 | 低位 | 基準 | 高位 |
| --- | ---: | ---: | ---: |
| 0台または対象外 | 20.0% | 10.0% | 5.0% |
| 1〜5台 | 45.0% | 37.0% | 25.0% |
| 6〜10台 | 24.0% | 28.0% | 25.0% |
| 11〜30台 | 9.0% | 20.0% | 30.0% |
| 31〜50台 | 1.5% | 3.0% | 9.0% |
| 51〜100台 | 0.4% | 1.5% | 4.0% |
| 101台以上 | 0.1% | 0.5% | 2.0% |
| 加重平均PC台数/社 | 5.90 | 9.85 | 17.15 |

加重平均は各帯の代表値（0、3、8、18、40、70、130台）による。これは精密な予測ではなく、価格・原価の感度を見るための仮定である。基準ケースは、Windows対象企業率を90%と置く。実測で置き換えるべき優先変数は、(a) 対象企業率、(b) 1〜10台企業比率、(c) 11〜30台企業比率、(d) 101台超の件数である。

前提: PIRA公表の約10,000社、Windows対象企業率90%、平均9.85台/社。導入率はWindows対象企業を母数にした感度分析であり、成約予測ではない。

| 1% | 90 | 約887 | 約716千円 | 約369千円 |
| 3% | 270 | 約2,660 | 約2,148千円 | 約1,106千円 |
| 5% | 450 | 約4,433 | 約3,580千円 | 約1,843千円 |
| 10% | 900 | 約8,865 | 約7,160千円 | 約3,686千円 |
| 20% | 1,800 | 約17,730 | 約14,319千円 | 約7,373千円 |

## 6. 料金適合性とボリュームディスカウント

### 小規模企業への見え方

| PC台数 | 現行月額 | 基本料金の構成比 |
| ---: | ---: | ---: |
| 3台 | 5,900円 | 84.7% |
| 5台 | 6,500円 | 76.9% |
| 10台 | 8,000円 | 62.5% |
| 20台（候補割引適用） | 10,500円 | 47.6% |

1〜5台では基本料金が支払理由の中心になる。従って「1台300円」とだけ訴求せず、標準ポリシー、端末外でも保護されるWindowsエージェント、初期導入、問い合わせ対応の提供範囲を明示する。価格改定の根拠はまだない。

### 割引案の評価

- 基準ケースの平均は10台未満であり、11台からの割引は小規模層の単価を守りつつ成長顧客に対応する。
- 高位ケース（平均17.15台）では、候補の限界単価制により一律300円に比べ端末料金が1社あたり約358円/月（約7%）低下する。割引原資は、個別見積の101台以上に集中させるより管理しやすい。
- 31台から200円に下げるかは未確定。運用工数、実MSP原価、競合見積、31台以上の実測構成比を取得してから決める。
- 一律300円は最も説明しやすいが、20〜100台で競争力を損なう可能性がある。候補案は「累進（限界）単価」であることを料金表に明記する。全台数に割引単価を遡及適用する方式とは区別する。

## 7. PIRA提案への示唆

1. **初期案内先**: 外国人材受入の研修・相談接点を持つ正会員をチャネル候補とし、傘下企業に直接一律配布する前に、組合別に対象業種・端末台数・案内可否を確認する。
2. **初回訴求**: 「フィッシング・マルウェアサイトへの接続をDNS段階で防ぐ」「社外利用のWindows端末も保護」「難しい運用を標準化」の3点を主軸とする。個別のセキュリティ効果を保証しない。
3. **無料診断**: 3分程度で従業員数、Windows PC台数帯、社外利用、既存対策、担当者を取得し、今回の主要未確認値を実測へ置換する。
4. **優先順位**: 企業数だけで順位を決めない。組合の案内協力、PC利用実態、情報システム担当の有無、導入支援の負荷を合わせて選ぶ。
