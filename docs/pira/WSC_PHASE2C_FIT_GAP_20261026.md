# WSC Phase 2C Fit / Gap（2026-10-26）

## 方式比較と採用

| 方式 | DNS/IP拘束 | Windows保守性 | 採用 |
|---|---|---|---|
| Node.js HTTPS/TLS/DNS | `tls.connect`で検証済みIPへ明示接続可能 | Node 20+で実行可能 | 採用（ただし外部実行は無効） |
| PowerShell v2の直接利用 | atLIB固定・ソケットIP拘束なし | 原本を改変できない | 不採用 |
| Phase 2B契約アダプター | 取得結果の検証契約を再利用 | 既存の隔離テストと整合 | 採用 |

`restricted-network-probe.mjs` は、承認済みの対象URLと承認トークンの両方が注入されない限り、外部接続前に必ず停止する。今回のテストはこの停止境界だけを通過し、実接続は一切実行していない。

## 実装契約

承認時だけ、Node標準DNSで解決した公開IPをPhase 2Aポリシーで検証し、TLS接続先をそのIPに固定する。SNI・Hostは元ホスト名、証明書検証は有効、リダイレクト追跡はなし、応答上限・AbortSignal・タイムアウトを適用する。ソケットの`remoteAddress`が固定IPと一致しなければ失敗する。

明示メールドメインだけをTXT照会し、SPF・DMARCをJSON 2.0形状で返す。メールドメイン未指定は推測せず未確認とする。

## 隔離テストとSTOP

テスト専用アダプターはネットワークモジュールを使わず、SNI・Host・TLS検証要求を模擬する。Phase 2B/2A/VS1回帰を併用する。実サイトへの接続、承認トークンの発行、実DNS／TLS、GCP、Productionは未実施。

実サイト試験には、対象URL一覧・所有または調査許可・頻度上限・実行時間帯・承認トークンの保管方法を統括承認すること。DNS再解決後の固定IPと実ソケット接続先を運用環境で照合できない場合はSTOPする。
